# Code of Conduct

gHALO uses the Contributor Covenant Code of Conduct, version 2.1, adapted for
this project.

## Our Pledge

We are committed to making participation in the gHALO community welcoming,
inclusive, respectful, and free from harassment for everyone.

## Our Standards

Examples of behavior that supports a healthy community include:

- using welcoming and inclusive language;
- respecting different viewpoints and experiences;
- giving and receiving constructive feedback gracefully;
- accepting responsibility, apologizing when needed, and learning from mistakes;
- focusing on what is best for the project and its users.

Examples of unacceptable behavior include:

- harassment, intimidation, threats, or sustained disruption;
- sexualized language, imagery, attention, or advances;
- insulting, derogatory, or demeaning comments;
- personal or political attacks in project spaces;
- publishing private information without explicit permission;
- conduct that would reasonably be considered inappropriate in a professional
  setting.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing community
standards. Maintainers may remove, edit, reject, or moderate contributions and
comments that do not align with this code of conduct.

## Scope

This code applies in all gHALO project spaces. It also applies when someone is
officially representing the project in public spaces, such as using an official
project account, email address, event role, or other appointed role.

## Reporting

Report code of conduct concerns privately to the project maintainers. Until a
dedicated security or conduct contact is published, use a private GitHub
maintainer contact or email the repository owner.

Reports will be reviewed promptly and fairly. Maintainers will respect the
privacy and security of reporters and affected community members.

## Enforcement Guidelines

Maintainers may respond with:

- clarification or correction;
- a private warning;
- temporary limits on participation;
- permanent removal from project spaces.

The response will depend on the impact, severity, and pattern of behavior.
